# Exhaustive REST API & WebSocket Reference

All ChiPanel API routes are served under the `/api` prefix on the configured port (`25500` by default). Responses use standard `application/json` formatting unless otherwise specified (e.g., raw file downloads, CSV exports).

---

## 🔐 1. Authentication & Security Mechanism

### Authentication Protocols
ChiPanel supports two authentication methods:
1. **JWT Bearer Token**: Returned upon login via `/api/auth/login`. Pass via the HTTP header:
   ```http
   Authorization: Bearer <JWT_TOKEN>
   ```
2. **Persistent API Access Key**: Generated by administrators via `/api/auth/tokens`. Pass via:
   ```http
   X-API-Key: chipanel_sec_<HEX_TOKEN>
   ```
   Or via `Authorization: Bearer chipanel_sec_<HEX_TOKEN>`.
3. **WebSocket Query Parameter**: When connecting to the WebSocket stream `/ws`, pass:
   ```
   /ws?token=<JWT_OR_API_KEY>
   ```

### Roles & Authorization (RBAC)
- **Public / None**: Endpoint accessible without authentication.
- **`AuthUser`**: Requires any valid user session or persistent API key.
- **`RequireAdmin`**: Requires an authenticated user holding the `admin` role (or the bootstrap `ADMIN_USERNAME`), OR a valid persistent `chipanel_sec_...` API token. Non-admin users receive `403 Forbidden`.

## 20. Real-time WebSocket Protocol (`/ws`)

The WebSocket endpoint provides zero-latency server telemetry streaming, live console output, and interactive command execution.

### Connection Handshake
- **URL**: `ws://<HOST>:25500/ws?token=<JWT_OR_API_KEY>`
- Handshake validates token credentials immediately. Invalid tokens are closed with code `4401 Unauthorized`.

### Client-to-Server Messages
Clients transmit JSON envelopes:
```json
{
  "type": "command",
  "command": "say Broadcast message from ChiPanel"
}
```
*(Command emission strictly requires `admin` role).*

### Server-to-Client Broadcast Messages

#### 1. Live Console Log (`console_log`)
```json
{
  "type": "console_log",
  "timestamp": 1723856238,
  "level": "INFO",
  "message": "[Server thread/INFO]: Player Steve joined the game"
}
```

#### 2. Server Telemetry Broadcast (`telemetry` — sent every 2 seconds)
```json
{
  "type": "telemetry",
  "podman_available": true,
  "container_running": true,
  "cpu_percent": 14.5,
  "memory_bytes": 3221225472,
  "memory_limit_bytes": 8589934592,
  "memory_percent": 37.5,
  "rcon_available": true,
  "tps": 20.0,
  "online_players": 4,
  "max_players": 20
}
```

#### 3. Deferred Command Notification (`pending_commands_executed`)
```json
{
  "type": "pending_commands_executed",
  "player_name": "Steve",
  "commands_count": 2,
  "actions": ["give", "lp_group"]
}
```
