# Product

## Register

product

## Users
Homelab administrators, server owners, and developers managing Minecraft servers and Podman containers locally or remotely via Tailscale.

## Product Purpose
ChiPanel is a high-performance, dark-mode-first homelab & Minecraft management console built with a Rust Axum backend and SvelteKit frontend. It provides real-time telemetry, container controls, log inspection, player management, and engine/modpack management.

## Brand Personality
Sleek, responsive, production-grade, tactile, dark-mode first.

## Anti-references
SaaS cliché dashboards with fake numbers, bloated sidebars, glassmorphism excess, cheesy emojis, and non-functional visual placeholders.

## Design Principles
1. Truth in Telemetry: Never display dummy data or fake static numbers. Render live metrics when connected, and clean, honest empty/loading/offline states when telemetry is unavailable.
2. Clean Iconography: Use precise Lucide vector icons instead of text emojis.
3. High Information Density & Clarity: Clear visual hierarchy, readable typography, dark-mode optimized contrast.

## Accessibility & Inclusion
WCAG AA compliance, 4.5:1 text contrast ratios, full keyboard navigation, and reduced-motion support.
